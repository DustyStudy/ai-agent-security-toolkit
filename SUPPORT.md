# Getting help

- **Questions and how-to:** open a [GitHub issue](https://github.com/DustyStudy/ai-agent-security-toolkit/issues/new/choose) using the bug or feature template. Include your Python version, OS and a minimal reproduction.
- **Security vulnerabilities:** report privately through [GitHub security advisories](https://github.com/DustyStudy/ai-agent-security-toolkit/security/advisories/new). See [SECURITY.md](SECURITY.md).
- **Scope:** this is a solo-maintained open-source project with no SLA. It is a set of defense-in-depth controls and measurement tools, not a complete defense. Read "Honest limitations" in the README before relying on it.
